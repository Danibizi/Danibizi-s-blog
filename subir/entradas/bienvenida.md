# Bienvenido al blog

Esta entrada es un ejemplo para que veas cómo se ve todo. **Bórrala cuando quieras**: está en la carpeta `subir/entradas`.

Para publicar algo nuevo solo tienes que subir un archivo `.md` a esa carpeta. No hace falta cabecera: el título, la fecha y la descripción se sacan solos.

## Código

```bash
nmap -sC -sV -p- 10.10.11.x
```

## Listas y tablas

- Markdown normal
- Texto copiado de Redmine (`.txt` o `.textile`)

| Carpeta | Para qué |
|---|---|
| `entradas` | Entradas y tareas |
| `htb` | Writeups de Hack The Box |
| `tryhackme` | Writeups de TryHackMe |

> Consejo: para la portada sube a `imagenes/` una imagen con el mismo nombre que el archivo.
