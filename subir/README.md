# Cómo subir una entrada

Arrastra tu archivo a la carpeta que corresponda y pulsa **Commit changes**. En 1-2 minutos está publicado.

| Carpeta | Para qué |
|---|---|
| `entradas/` | Entradas normales y tareas |
| `htb/` | Writeups de Hack The Box |
| `tryhackme/` | Writeups de TryHackMe |
| `imagenes/` | Capturas y portadas |

**Cómo:** abre la carpeta en GitHub → **Add file → Upload files** → arrastra → **Commit changes**.

## Qué archivos valen
- `.md` o `.markdown` (Markdown normal, con o sin cabecera).
- `.txt` o `.textile` con texto copiado de **Redmine**: se convierte solo.

## No hace falta nada más
- El **título** sale del primer `# Título` (o del nombre del archivo).
- La **fecha** es la de cuando lo subes.
- La **descripción** es el primer párrafo.
- **Imágenes:** súbelas a `imagenes/` y escribe solo el nombre: `![captura](captura.png)`.
- **Portada:** sube a `imagenes/` una imagen con el mismo nombre que el archivo (`mi-entrada.md` + `mi-entrada.png`).
- Para borrar una entrada, bórrala de esta carpeta.
